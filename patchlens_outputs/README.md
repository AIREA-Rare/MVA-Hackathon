# PatchLens outputs

The only place PatchLens results are published in this repository.

- Records go in [`records/`](records/). Specification: [`SPEC.md`](SPEC.md). Schema: [`patchlens_output.schema.json`](patchlens_output.schema.json).
- [`examples/`](examples/) holds a fictional record that shows the format. It is not a result.
- Allowed file types here: `.json`, `.md`.
- Never add PatchLens code, parameters, weights, caches, logs or structure files. See [CONTRIBUTING.md](../CONTRIBUTING.md).

Each record is structural evidence at tier E4 with `call: null`.
