# References and access levels

**Numbering.** The numbers are the same as in `AIREA_track2_report.md` (section 18).

**Verification.** Bibliographic details were verified against Europe PMC records on 2026-10-24. Database and software citations follow each provider's own citation guidance where it could be read:
- **gnomAD:** its citation policy;
- **AlphaFold DB:** its README.
- **ClinVar:** its citation page could not be loaded (browser check), so the ClinVar team's latest database-issue article is cited.

**Access levels.** The column records what was actually read:

| Level | Meaning |
|---|---|
| Full text | Read in full |
| Abstract | Raw abstract via the Europe PMC API |
| Bibliographic | Metadata only |
| Database/release | The resource version used |
| Database page (summary) | Read in K2 through a summarising web-fetch tool, so a tool summary of the page, not raw text |

A claim drawn from an abstract can be wrong about details that only the full text gives.

**Claim IDs.** The last column gives the claim's ID in the team's internal evidence ledgers (WP2, K3, K5, K6). The ledgers are restricted and not published; the IDs let the team trace each claim to its source record.
